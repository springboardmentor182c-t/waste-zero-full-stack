# Edit Post UI (Angular 15)
Minimal Angular 15 scaffold containing an **Edit Post** UI component with:
- Reactive form with validation
- Live preview
- Stubbed PostService (replace with HttpClient API calls)
- SCSS styles, simple responsive layout

## How to use
1. Install dependencies: `npm install`
2. Run: `npm start` (requires Angular CLI)
3. The Edit Post page is at `/` by default.

This is a lightweight scaffold meant for integration into an existing Angular workspace.
